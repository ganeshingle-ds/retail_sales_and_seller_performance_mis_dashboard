# retail_sales_and_seller_performance_mis_dashboard

## 📌 Project Overview

This project features an interactive and automated Management Information System (MIS) Dashboard built entirely in *MS Excel*. The main objective is to transform raw retail transaction records into actionable business insights. It provides senior management with a clear, bird's-eye view of total sales revenue, regional market performance, and individual seller metrics.

* *Total Revenue Tracked:* INR 40,87,950
  
* *Total Quantities Sold:* 1,434 units
  
* *Target Audience:* Operational Heads, Sales Managers, and Procurement Teams
  

---

## 🛠️ Key Features & Architecture

1. Data Structuring & Cleaning (Data Sheet):
   
   Organized raw transactional datasets containing critical parameters:
   
   Serial Numbers, Seller Names, Regional Cities, Dates, Items, Quantities, Unit Rates, and Total Sales.
   
   Ensured 100% data integrity by applying data validation and structural formatting before running analytical models.

   
2. Multi-Dimensional Data Aggregation (PivotTable Sheet)
   
    Utilized advanced Pivot Tables to compute complex summaries dynamically without heavy formulas.
   
    Temporal Analysis: Aggregated monthly revenue streams to identify seasonal spikes (Jan to Apr).

     
3. Geographical Distribution & Metrics:
 
    Regional Profiling: Grouped sales metrics by cities (*Sitapur, Lucknow, Lakhimpur*) to locate high-performing regions.

    Product SKU Metrics: Summarized total inventory flow based on the total quantity of each item sold.
   
    Performance Matrix: Generated rank-wise sales revenue generated by individual sellers (e.g., *Shivam Verma, Gajendra Singh, Abhishek Dixit*).
  
     
4. Executive Visualization (Dashboard & Seller Sheets):
   
    Designed a visually cohesive, dark-themed analytical interface consisting of:
   
    KPI Blocks: Bold callouts highlighting core financial numbers like the Total Sale Amount (*INR 40,87,950*).
     
    Dynamic Slices: Interactive filtering buttons for Cities and Items allowing users to switch contexts instantly.
     
    Timeline Controller: A sleek calendar timeline slider allowing multi-month or specific date range analysis.

# Visual Charts
    Pie Chart:  Displays the percentage contribution of each hardware component's volume.
  
    Bar/Column Charts:  Displays City-wise sales volumes and individual Seller performance comparisons.
  
    Trend Line Graph:  Illustrates Month-wise sales growth trajectories.
